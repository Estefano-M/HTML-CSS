Aqui nessa aula falamos sobre dois novos atributos:
REQUIRED(requerido/obrigatório) = quando a gente quer que o usuário não deixe de preencher essa informação pois ela é essencial na hora de enviar os dados para o servidor. Como nesse exemplo aqui quando a pessoa for acessar a conta dela, o usuário e o password é required

Aprendemos também sobre o atributo: INPUT:TYPE="RESET"
Quando a gente cria uma caixa de formulário e quando os usuáros quiserem apagar todas as informações de uma vez ao invés de ir apagando uma por uma como no exemplo acima ↑

Aprendemos também os atributos:
MINLENGHT e MAXLENGTH = Como a gente já leu no livro, esse atributo determina o tamanho mínimo de caracteres e o tamanho máximo!
Isso para colocar em senhas, passwords, etc é ótimo!

Aprendemos também sobre o atributo:
SIZE = Ele vai determinar o tamanho da caixa de preenchimento do formulário. Aqui nesse exemplo, eu coloquei a senha com o size 10. Ao você preencher totalmente o valor definido, ao chegar no valor ele vai deslizar a tela para o lado!

Aprendemos também sobre o atributo:
PLACEHOLDER = É quando a gente quer deixar uma dica para o usuário sobre o que que ele tem que preencher naquele campo de texto ou como no caso do password, quantos caracteres mínimos é necessário preencher!

Aprendemos também sobre o atributo:
AUTOCOMPLETE = Quando a gente coloca o autocomplete="on" no formulário, todas as informações que o usuário já preencheu anteriormente irão aparecer para ele. Mas temos novas coisas chegando aqui e são elas:
No caso da senha por exemplo que ele tem que preencher para conseguir acessar a conta dele, a gente pode usar o atributo com o valor:
autocomplete="current-password" ou seja, como diz o próprio nome do valor, ele vai usar o autocomplete mas se referindo a senha atual dele!
Quando for uma nova senha que o usuário tem que se cadastrar, podemos usar o atributo autocomplete com o valor new-password!
