O recomendado é criar um documento separado e com CSS para colocar aqui dentro do iFrame como eu fiz nos links ali em cima. Aqui, o Guanabara nos quis mostrar uma nova propriedade mas não é a melhor opção.

Essa aula foi bem legal de aprender. Isso de conseguir abrir uma página dentro do iFrame ou clicar no link foi legal.

Quando faz sentido usar o Iframe com conteúdo local:

  • Pré-Visualização de páginas ou documentos
    • Visualização de Templates, Relatórios ou temas HTML
    • Demonstração de comportamento de interfaces (modo "sandbox") Esse aqui é pra segurabça que vamos ver mais pra frente.
  • Separação de Contexto de Execução
    • Prevenir conflitos de CSS/JS
    • Simular carregamento externo
    • Separar responsabilidades (ex: um editor HTML e um painel de visualização ao lado)
  • Testes ou Protótipos
    • Durante o desenvolvimento, pode ser útil simular a navegação ou comportamento de links dentro de um iFrame com páginas locais.
  • Cuidados mesmo com conteúdo local
    • SEO: conteúdo do iFrame não é indexado da mesma forma
    • Acessibilidade: leitores de telas menores podem não ler bem o conteúdo embutido
    • responsividade: precisa garantir que o iFrame se adapte bem a telas pequenas
    • Performance: se você carregar muitas páginas em iFrames simultaneamente, pode pesar no DOM (at this moment, i don't know what this is)
