Aprendi que uma Media Query é a mesma coisa que,(ou igual á) Media Type + Media Features!
Ou seja, Media Type é o tipo de Media e o Media Feature é a característica de Media!
Por exemplo na aula passada(introdução ao Media Types) que falamos sobre a Media Screen. A Media Screen é o Media Type mas o Media Features vai ser a característica dessa Media pois existem vários tamanhos de tela!

Aprendemos aqui que ao usar o Media Type, a gente pode colocar a característica do FEATURE dentro do parenteses()! Vejo no exemplo que está no VSCODE e aqui em baixo: ↓

                
                    link rel="stylesheet" href="styles/feature.css" media="all"
                    link rel="stylesheet" href="styles/portrait.css" media="screen and (orientation: portrait)"
                    link rel="stylesheet" href="styles/landscape.css" media="screen and (orientation: landscape)"

Como já está auto-explicativo, o MEDIA TYPE ALL vai englobar todas as configurações das Media Types!
