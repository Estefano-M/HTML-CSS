O elemento <OUTPUT> não é feito para ser enviado pois ele ao ser enviado para o servidor, ele não vai mostrar o valor! Ele serve apenas para ser mostrado para o usuário como diz o próprio nome dele!

Dentro do nosso <INPUT:NUMBER> a gente usou o atributo <ONINPUT> e colocamos os valores para esse atributo. Essa parte aqui literalmente foi usado valores da linguagem de programação JavaScript para que a gente pudesse realizar essa aula!
