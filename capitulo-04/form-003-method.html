Quando usar GET ou POST?

Usando o GET

Quando usar o atributo METHOD com o valor GET, é quando você está solicitando dados dos usuários como por exemplo: Altura, nome, peso, etc. Nada que venha conter informações sensíveis. Que nem a gente quando vai fazer uma pesquisa no Google!
A gente não coloca informações sensíveis no search bar do Google!
Quando a gente usa o method="get", as informações aparecem na cara do usuário na barra de endereço.
Quando a gente usa o method="get", a gente pode pegar as informações que estão na barra de endereço e compartilhar aquele link com mais alguém que nem a gente faz quando quer enviar um link para outra pessoa.

Outra coisa, quando for enviar dados usando o method get, só pode enviar dados em até 3000 bytes é aproximadamente 3 mil letras do formulário completo que o usuário está enviando.

Não usar o method get também quando o usuário for enviado arquivos e fotos.

Usando o POST

Quando usar o valor POST, é quando a gente está coletando dados sensíveis dos usuários como senhas, numero do cartão de crédito, endereço, CEP, etc.
Outra coisa também é quando a gente quer mudar algo no servidor(enviando um formulário, salvando dados, etc).
