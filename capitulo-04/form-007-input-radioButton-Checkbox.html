Quando a gente usa o elemento <RADIO>, quando a gente seleciona uma opção, a gente não consegue desmarcar! Para que a gente corriga esse "erro", a gente precisa fazer com que o atributo <NAME> tenha o mesmo valor que a outra opção para que quando a gente clicar em uma opção(por exemplo "sexo" no exemplo acima), o valor(a opção escolhida) seja selecionado desmarcando a outra opção!
Ou seja, todas as opções de RADIO BUTTON tem que ter o mesmo valor para o atributo NAME!
O atributo ID tem que ser diferente para que o botão funcione pois são valores(opções) diferentes!

Essa dica aqui de cima não se aplica ao elemento <CHECKBOX>! Somente quando se trata de RADIO BUTTONS!
