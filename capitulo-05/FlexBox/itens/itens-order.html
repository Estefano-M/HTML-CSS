Order:

Ao usarmos a tag order, iremos definir como já diz o nome, a ORDEM (ou seja, quem aparecerá primeiro de acordo com o valor colocado nele)!

Temos duas formas de colocar a tag e assim, alterarmos a ordem do item:
Primeiro, nós temos o inline style o que nos é instruído a não usar ou usar pouco.
Segundo, nós temos a forma de criar um id e configurarmos ele no CSS.

O exemplo a seguir foi feito usando o INLINE-STYLE: 

                
                    div class="item" style="order: -3">
                    div class="item" style="order: 2">
                    div class="item" style="order: 4">

A outra forma de fazer é colocando um ID no item e depois colocando no CSS como no exemplo abaixo: 

                
                    style{
                        div#i7{
                            order: -3;
                        }
                        div#i6{
                            order: 1;
                        }
                    }

Lembrando que ao deixar o content/item, sem um order, o valor padrão dos item é 0. Ou seja, se eu definir uma ordem e deixar algum item sem ter uma ordem definida(e nem ter um valor negativo), ele vai ficar com o valor padrão 0 e vai ser o primeiro da lista.
Numeros negativos vão vir antes. Eis a order: negativo> 0 > outros valores (positivos).
Ou seja, para resumir: TODO ELEMENTO QUE ESTIVER DENTRO DO CONTAINER POR PADRÃO VAI TER O ORDER: 0!

Isso é mais usado em exeplos que ao estiver em uma tela de celular, a ordem dos elementos mudam. O menu se desloca para outro lugar por exemplo. Quando colocar em uma tela maior, o menu se desloca para outro lugar e assim com todos os tamanhos de telas caso queira.

Align-Self:

O align-self se aplica diretamente nos itens e ele vai funcionar diretamente no CROSS-AXIS(eixo transversal)!
O align-self tem 5 valores e são eles:

  • Auto;
    • O valor auto; vai erdar a característica de alinhamento do seu pai.
  • Flex-Start;
  • Flex-End;
  • Center;
  • Stretch;
