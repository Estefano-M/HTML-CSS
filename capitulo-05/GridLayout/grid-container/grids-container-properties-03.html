Propriedades de Container do Grid Layout

Nessa aula, iremos aprender novas propriedades de Container do Grid Layout. E iremos falar sobre as seguintes propriedades:

  • grid-auto-row
  • grid-auto-column
  • place-items
  • place-content
  • grid-template

- grid-auto-row:

Quando a gente coloca os valores: 100px 100px 100px no grid-template-row, a gente cria uma grid com 3 linhas de 100px cada item.
Mas ao colocarmos uma quarta linha, ele irá ficar com um tamanho menor e visualmente falando incompatível com os demais items como nesse exemplo abaixo.

Caso eu queira que, ao adicionar uma nova linha(ou item) ela venha com a mesma altura que as demais, devo usar a propriedade grid-auto-row: 100px pois assim, cada vez que for adicionado uma nova linha, esse item terá o mesmo tamanho que as demais(eu escolherei o tamanho ao colocar o valor px ou auto). - grid-auto-column:

Da mesma forma que o exemplo acima opera, essa propriedade grid-auto-column faz a mesma coisa.

Quando é criado células(sejam column ou row) que estão fora do grid, são chamadas de GRID IMPLÍCITO. As criadas dentro da grid são chamadas de grid explicito. Ou seja, foram pré-definidas.
